Principles

Built so a compliance officer can trust it - and a reviewer can attack it.

01

The score is arithmetic, not vibes

Evidence signals fuse with a noisy-OR. Every signal owns an exact share of the final score, so the waterfall always sums to it - and counterfactuals say what would change the outcome.

02

The LLM is advisory

AI findings become unverified evidence with a hard uplift cap. They can raise a score, never lower it, so a prompt-injected "mark as low risk" is inert - and the attempt itself is scored as suspicious.

03

Sanctions matching with a policy

Token-aligned Jaro-Winkler with a phonetic skeleton. Only exact entity matches trigger an automatic floor; fuzzy hits go to an analyst. Loads the official OFAC SDN list.

04

A graph that remembers

Fan-in, fan-out, pass-through and 2-5 hop round-trips over edges persisted across analyses - a cycle spread over three separate requests is still found.

05

Regulation is a parameter

US BSA (SAR, 30 days), India PMLA (STR in 7 working days, CTR above ₹10 lakh) and EU rules change thresholds, currency conversion and report deadlines.

06

Private by default, auditable always

Web search is off, identifiers are redacted, confidential subjects are never searched. Every state change joins a hash chain you can verify - or detect tampering in.

Architecture

A deterministic core with an optional, capped AI layer.

screenDeterministic engine: sanctions, PEP, geography, behaviour, graph, crypto, trade
researchGuarded ReAct agents. Only if requested, configured and not already conclusive
scoreNoisy-OR fusion, policy floors, AI uplift cap, decision
synthesizeAnalyst briefing - narrative only, never changes the score
reportSAR / STR draft when filing is warranted

# deterministic analysis, no API key needed locally
curl -s localhost:8000/api/v1/analyze \
  -H 'content-type: application/json' -d '{
  "transaction": {"amount": 500000, "origin_country": "RU",
    "destination_country": "KY", "intermediate_countries": ["AE","CH"],
    "parties": ["Cayman Holdings Limited"]},
  "customer": {"name": "Moscow Trading LLC",
    "customer_type": "CORPORATE", "account_age_days": 45},
  "enable_llm_analysis": false }'
